# Mobile editor reference findings

- Microsoft Word for Android touch guide: tap an object, hold and drag to move it; drag any resize handle to resize it; drag a rotation handle to rotate it. It also documents pinch zoom and drag selection handles for text.
  Source: https://support.microsoft.com/en-us/word/word-for-android-touch-guide
- Microsoft table touch guide: tap above a column or in front of a row to expose handles; drag handles to resize rows and columns; drag the handle at the bottom of the table to resize the whole table.
  Source: https://support.microsoft.com/en-gb/word/resize-table-columns-and-rows
- WPS Office Mobile image guide: select an image, then use the image toolbar for exact width/height and an optional lock-aspect-ratio setting; manual resizing exposes eight drag handles. WPS also describes resizing text boxes/shapes and picture tools.
  Source: https://www.wps.com/academy/how-to-resize-image-in-wps-office-in-mobileeasy-and-simple-quick-tutorials-1877498/
- WPS Docs table tools guide: supports selecting a table range by dragging, dragging table borders, row/column insertion and deletion, merge cells and split cells.
  Source: https://help.wps.com/c/wps-docs-editing-collaboration/2104742033792552962-wps-docs-table-tools-feature-guide-for-mac
- Microsoft arrange/wrap references: objects support bring forward/send backward and text wrapping; multiple objects can be selected and grouped/arranged.
  Sources: https://support.microsoft.com/en-us/office/align-or-arrange-objects and https://support.microsoft.com/en-gb/word/wrap-text-and-move-pictures-in-word
- Microsoft mobile margins reference: margins are exposed through the Layout > Margins controls.
  Source: https://support.microsoft.com/en-us/office/change-margins-in-office-apps-on-your-mobile-device
