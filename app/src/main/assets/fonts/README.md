# Bundled fonts

The Arabic typefaces currently bundled from Google Fonts are distributed under SIL Open Font License 1.1 (OFL). Their individual license texts are stored beside the font files.

- Noto Sans Arabic, Noto Sans, Noto Serif: https://github.com/google/fonts/tree/main/ofl/notosansarabic , https://github.com/google/fonts/tree/main/ofl/notosans , https://github.com/google/fonts/tree/main/ofl/notoserif
- Noto Kufi Arabic (Kufi): https://github.com/google/fonts/tree/main/ofl/notokufiarabic
- Scheherazade New (Naskh-oriented Arabic text face): https://github.com/google/fonts/tree/main/ofl/scheherazadenew
- Katibeh (decorative display face with Thuluth influence; it is not represented as a dedicated Thuluth font): https://github.com/google/fonts/tree/main/ofl/katibeh
- Aref Ruqaa (Ruqaa): https://github.com/google/fonts/tree/main/ofl/arefruqaa
- Amiri (Naskh): https://github.com/google/fonts/tree/main/ofl/amiri
- Reem Kufi: https://github.com/google/fonts/tree/main/ofl/reemkufi

Google Fonts family pages describing Noto Kufi Arabic, Scheherazade New, and Katibeh: https://fonts.google.com/noto/specimen/Noto+Kufi+Arabic ; https://fonts.google.com/specimen/Scheherazade+New ; https://fonts.google.com/specimen/Katibeh
