# Bundled fonts

The editor bundles its fonts locally so text formatting works offline and does not depend on fonts installed on a device.

Arabic families include Noto Sans Arabic, Amiri, Cairo, Tajawal, Noto Naskh Arabic, and Noto Kufi Arabic. Latin/English families include Noto Sans, Noto Serif, Roboto, Open Sans, and Montserrat.

Sources are the official Google Fonts repository: [Noto Sans Arabic](https://github.com/google/fonts/tree/main/ofl/notosansarabic), [Noto Sans](https://github.com/google/fonts/tree/main/ofl/notosans), [Noto Serif](https://github.com/google/fonts/tree/main/ofl/notoserif), [Amiri](https://github.com/google/fonts/tree/main/ofl/amiri), [Cairo](https://github.com/google/fonts/tree/main/ofl/cairo), [Tajawal](https://github.com/google/fonts/tree/main/ofl/tajawal), [Noto Naskh Arabic](https://github.com/google/fonts/tree/main/ofl/notonaskharabic), [Noto Kufi Arabic](https://github.com/google/fonts/tree/main/ofl/notokufiarabic), [Roboto](https://github.com/google/fonts/tree/main/ofl/roboto), [Open Sans](https://github.com/google/fonts/tree/main/ofl/opensans), and [Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat).
