Bundled fonts

This directory contains variable TTF fonts from the Google Fonts repository:
- Noto Sans Arabic: https://github.com/google/fonts/tree/main/ofl/notosansarabic
- Noto Sans: https://github.com/google/fonts/tree/main/ofl/notosans
- Noto Serif: https://github.com/google/fonts/tree/main/ofl/notoserif
